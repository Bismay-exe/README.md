# `01 / WHAT IS THIS?`

Not another blog template.

Not a page with a title, a paragraph, and a comment section pretending to be interesting.

**blogs.bismay** is a personal publishing experience built around two things:

```text
WRITE BETTER
     +
READ BETTER
```

The writing side gives content a structured Markdown-based workflow.

The reading side gives the reader control over how that content feels.

And somewhere between those two things lives everything else:

* Rich articles
* Markdown formatting
* Code examples
* Media embeds
* Reader customization
* Typography
* Motion
* Interactive experiments
* Series
* Categories
* RSS
* Search engine discovery

The goal is simple.

> **The content should be yours. The reading experience should feel like theirs.**

# `29 / HOW IT'S ORGANIZED`

The project uses the **Next.js App Router** and separates different responsibilities across routes, components, utilities, and content.

```text
blogs.bismay/
│
├── app/
│   ├── about/
│   ├── admin/
│   ├── api/
│   ├── blogs/
│   ├── categories/
│   ├── series/
│   ├── settings/
│   ├── rss.xml/
│   ├── layout.tsx
│   ├── page.tsx
│   ├── sitemap.ts
│   └── robots.ts
│
├── articles/
│
├── components/
│   ├── animate-ui/
│   ├── blog/
│   ├── motion/
│   ├── pixel-perfect/
│   ├── providers/
│   ├── settings/
│   └── ui/
│
├── lib/
│
├── public/
│
├── package.json
├── next.config.ts
├── tsconfig.json
└── README.md
```

The architecture keeps the application flexible by separating:

```text
CONTENT
   ↓
ROUTES
   ↓
COMPONENTS
   ↓
EXPERIENCE
```

# `30 / RUN IT YOURSELF`

## Requirements

You'll need:

* **Node.js**
* **npm**

Check that they're installed:

```bash
node --version
npm --version
```

---

## Clone the repository

```bash
git clone https://github.com/Bismay-exe/blogs.bismay.git
```

Move into the project:

```bash
cd blogs.bismay
```

---

## Install dependencies

```bash
npm install
```

---

## Start the development server

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```
